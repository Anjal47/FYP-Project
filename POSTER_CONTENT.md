## Introduction

- AngelTouch is a full-stack mobile application designed to support users through emergency access, digital reporting, counseling, therapy, NGO connection, and donation features.
- The system provides one platform for crime reporting, municipal complaints, mental health support, and quick access to trusted services.
- It is intended to make support services more accessible, organized, and user-friendly.

## Aims And Objectives

**Aim:**

To develop a secure and user-friendly mobile application that improves access to reporting, emergency response, counseling, and support services.

**Objectives:**

- develop secure user registration and login
- allow users to submit different types of reports with location and media
- provide emergency SOS and quick helpline access
- support counseling and therapy booking with chat
- connect users to NGOs and support organizations
- provide donation and charity request features
- create role-based dashboards for different service providers

## Problem And Solution

- Existing support systems are often separated into different services, making it difficult for users to quickly access help in urgent or sensitive situations.
- Many users need a simple mobile platform that combines reporting, emergency support, counseling, and community help in one place.
- AngelTouch addresses this problem by integrating these services into a single application with a clear and accessible interface.

## Key Features

- secure registration and login
- role-based access for user, admin, counsellor, therapist, police, and municipality staff
- digital reporting for crime, traffic, and municipality cases
- emergency SOS for police, ambulance, and saved personal contact
- counseling and therapy booking with chat support
- NGO directory with quick contact options
- donation and charity request support

## Technologies Used

- Frontend: React Native
- Backend: Node.js + Express.js
- Database: MongoDB + Mongoose
- Authentication: JSON Web Token (JWT)
- Real-time communication: Socket.IO
- File upload: Multer
- Local storage: AsyncStorage
- Version control: Git + GitHub

## Project Process / Methodology

The project follows the **Incremental Model**.

- requirement gathering and problem analysis
- design of core user interface and navigation flow
- development of authentication module
- development of reporting features
- development of counseling and therapy features
- development of emergency, NGO, and donation modules
- integration of admin and staff dashboards
- testing, refinement, and final documentation
